watches-backup

作者本人が、自分のデータベースのバックアップを自分の Google ドライブに保存するための個人用ツールです。作者以外は使いません。

Google ドライブで扱うのは、このツールが作成したファイルとフォルダだけです（スコープ drive.file）。ほかのファイルを読んだり変更したりすることはありません。

watches-backup is a personal tool used only by its owner to store the owner's own database backups in the owner's Google Drive. It can access only the files and folders it creates (drive.file scope).
