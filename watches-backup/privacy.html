プライバシーポリシー

watches-backup は、作者本人が自分の Google ドライブにバックアップを保存するためだけに使う個人用ツールです。

  • Google ドライブで扱うのは、このツールが作成したファイルとフォルダだけです（スコープ drive.file）。
  • 個人情報や利用状況のデータは収集しません。
  • データを作者以外の第三者に送信・提供・販売することはありません。
  • 認証情報は作者のパソコンの中にだけ保存されます。
  • Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

Privacy Policy

watches-backup is a personal tool used only by its owner to store backups in the owner's own Google Drive. It accesses only the files and folders it creates (drive.file scope), does not collect personal or usage data, and does not send, share, or sell any data to third parties. Credentials are stored only on the owner's computer. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
